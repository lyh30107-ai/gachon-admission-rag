# 수업 평가 결과

[평가 결과 엑셀 다운로드](./이윤형_202235088.xlsx)

이 파일은 프로젝트 작성자가 제공한 기존 수업 평가 기록입니다. 파일명은 한글 정규화(NFC)만 적용했으며, 엑셀 내용과 서식은 원본 그대로 보존했습니다. 이번 업로드를 위해 모델을 다시 실행하거나 답변을 재채점하지 않았습니다.

## 성적표에 기록된 결과

| 항목 | 기록 |
| --- | --- |
| 평가 문항 | 50문항 |
| 실행 횟수 | 문항별 3회, 총 150개 응답 |
| 최종 정답 판정 | 3회 중 2회 이상 정답 |
| 최종 정답 문항 | 35 / 50 |
| 문항 단위 정답률 | 70% (위 최종 판정 기준) |
| 정확성 점수 | 56 / 80 |
| 시간 점수 | 14 / 20 |
| 총점 | 70 / 100 |

`평가 결과` 시트에는 질문, 회차별 학생 응답, 응답 시간(초), 회차 판정, 최종 판정, 평균 시간, 문항 점수가 포함되어 있습니다. 성적표의 주석에 따르면 시간은 기존 성적표의 3회 평균이고 점수는 기존 평가 결과입니다. 시간 점수를 전체 질문의 응답 속도나 5초 이내 응답 비율로 해석하지 않습니다.

업로드 전 50문항·150개 응답과, 회차 판정의 다수결로 계산한 최종 정답 35문항이 성적표의 집계와 일치하는지 확인했습니다. 채점 기준의 타당성이나 개별 답변의 사실성을 재검증한 결과는 아닙니다. 실행 당시 코드 커밋·모델 버전·환경에 대한 독립적인 기록은 이 파일만으로 확인할 수 없으므로, 현재 저장소 버전의 재현 실험 결과로 단정하지 않습니다.
